# FPS Stells Level

Стелс-игра от первого лица в закрытом исследовательском комплексе. Исследуйте лаборатории и технические помещения, наблюдайте за патрулями и выбирайте момент, чтобы пройти незамеченными. Охрана реагирует на шаги, выстрелы и движение в поле зрения.
